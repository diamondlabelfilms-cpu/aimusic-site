# Privacy Policy

Last updated: July 12, 2026

AI Music Pipeline is an internal publishing tool operated by Diamond Label Films. It publishes our own content to our own social media accounts.

1. **No personal data collected.** The tool has no public users, no sign-up, no analytics, no cookies, and no tracking. This website is a static informational page and collects nothing.
2. **Platform tokens.** The tool stores API access tokens for the social media accounts we own (issued via each platform's official consent flow, e.g. TikTok Login Kit). Tokens are stored privately, used only to upload and publish our own content, and can be revoked at any time from the platform's account settings.
3. **No third-party sharing.** We do not sell, share, or transfer any data to third parties.
4. **Data deletion.** Disconnecting the app in the platform's settings revokes its access; stored tokens for that account are then deleted. Contact: diamondlabelfilms@gmail.com
